# BiciTV - Project Overview

## About
A platform combining cycling culture and psychedelic music.

## Features
| Feature | Description |
|---------|-------------|
| Music Player | Streaming psychedelic tracks |
| Cycling Content | Routes, tips, community |
| Events | Live events and meetups |
| Community | Social features for cyclists |
